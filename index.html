Gabungkan laporan supervisi jadi satu laporan

Unggah laporan supervisi pembelajaran mendalam dalam bentuk Word (.docx) atau PDF. Satu file boleh berisi banyak laporan. Semua dibaca di perangkat ini; tidak ada file yang dikirim ke server.

1. Unggah laporan

File Word lama berformat .doc belum bisa dibaca; simpan ulang sebagai .docx. PDF hasil pindai (gambar) tidak punya teks dan tidak bisa dibaca.

    2. Periksa hasil bacaan

    Buka satu laporan untuk memperbaiki skor atau identitas. Laporan di bawah ikut berubah.

    3. Laporan gabungan
